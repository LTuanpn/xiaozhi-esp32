# Kiểm thử và hoàn thiện biểu cảm

- Đưa chế độ nói, biểu cảm do Cloud gửi, timeline câu nói và tool về cùng đường chọn gói. Ghi rõ fallback khi gói không có tên tương ứng.
- Khi gói vẽ toàn màn hình, bỏ lượt vẽ mắt cũ phía sau. Xuất Nam và Nữ 20 FPS để khớp nhịp LVGL và kiểm tra dung lượng.
- Giữ hai gói đã phát hành, thêm lựa chọn quay về RoboEyes tích hợp, nâng nền có chiều sâu và thêm chế độ xem tuần tự trên trang LAN.
- Build firmware 2.5.6, xuất riêng app TFT 240×240 lên GitHub Release, thử gán từ Fleet và xác nhận robot khởi động đúng phiên bản.
