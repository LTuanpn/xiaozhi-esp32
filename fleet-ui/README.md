# Xiaozhi Fleet UI

Dashboard React, Vite và shadcn cho Music MCP. Build bằng `npm ci` và
`npm run build` trong thư mục này. Music MCP phục vụ bản build tại
`http://127.0.0.1:8766` khi bật `FLEET_ENABLED=1`.

Xem [cách chạy server, đăng ký robot và phát hành OTA](../mcp_music_server/README.md#dashboard-xiaozhi-fleet).
